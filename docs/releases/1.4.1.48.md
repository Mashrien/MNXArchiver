# MNXArchiver 1.4.1.48 — initial public prerelease

Downloads: **mnx-gui** Linux RPM/DEB/tar and a Windows x64 ZIP.
Install MNXFile separately first. Linux contains MWin/GTK4 (preferred) and the native
GTK3 fallback in one NativeAOT binary. Keep the supplied Skia/HarfBuzz libraries
with the portable executable. Windows uses the designer-editable MWin/WinForms UI.

The Linux RPM/DEB installs desktop/MIME resources and Dolphin's **MNX Archive**
submenu (Add/Create, Extract Here, Extract To). Windows Explorer shell integration
is not installed by the ZIP. The GUI includes archive navigation/search, serialized
operations, owned progress/cancel dialogs, queue resume and in-memory previews.
Previews/animation remain experimental and honor configured memory/window limits.

GTK4 >=4.12 enables MWin; GTK3 >=3.24 enables the fallback. Optional password
saving requires `secret-tool` and an unlocked desktop Secret Service. Error dialogs
use embedded icons, including when no desktop icon theme is present.

Wayland controls independent window placement; some preview positioning may differ
from X11/Windows. Linux trimming warnings from the toolkit remain; the actual AOT
binary is exercised rather than treating compilation as runtime validation.

## Purpose and package layout

MNX was created for very large network archives and NAS backups. Its complete
front index supports inexpensive browsing/search, and payloads stream through
bounded buffers rather than loading an archive into memory.

The engine is independently installed. Install MNXFile before the CLI or GUI;
neither interface contains a private engine. Native ABI 1/application protocol 1.
This is the first public prerelease. Disk schema MNX7 does not support old MSX
prototypes. Controlled cancel/resume is not a power-loss journal.

## Platforms

- Linux x86-64: NativeAOT, built on Ubuntu24.04; requires glibc2.39+ and OpenSSL3.
- Windows10 x64: native engine and both CLIs use AOT. WinForms GUI is self-contained
  single-file, not AOT. No installed .NET runtime is required by these binaries.
- Native payloads use .NET runtime/ILCompiler10.0.14. Linux SDK10.0.403;
  Windows SDK10.0.402. ARM64 releases are not supplied.
- SHA256SUMS covers the release downloads. Packages are unsigned; use the published
  hashes to check download integrity.

## Validation

The actual Linux AOT binary passed backend/INI checks, offscreen MWin tests, and
real GTK4/MWin plus GTK3 workflows under isolated Xvfb on Ubuntu24.04. Checks
include navigation, previews, Unicode, transfers, owned progress, cancellation and
encrypted resume. The Windows10 self-contained GUI passed all nine smoke sections.
