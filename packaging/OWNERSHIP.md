# GUI package ownership

The GUI package owns `mnx-gui`, its application icon, `org.mash.MNXFile.desktop`, the MNX MIME definition, and Dolphin service menu. It requires the independently installed MNXFile engine runtime providing `libmnxfile.so.1` with application protocol 1/C ABI 1, plus at least one backend toolkit (GTK4 for MWin, GTK3 for native) and the actual dependencies from `linux/DUAL-DEPENDENCIES.txt`. An RPM on a 64-bit target should express `libmnxfile.so.1()(64bit)` and a package/protocol requirement compatible with this client.

Install resources under the distribution's standard application, icon, MIME and KIO service-menu locations. The launcher uses `mnx-gui -- %F`; extraction actions use the documented `--extract-here`/`--extract-to` switches. Creating archives from selected files invokes `mnx-gui -- %F`. Do not hardcode the developer's paths or shell aliases. Refresh MIME/desktop caches using package-manager scriptlets appropriate for the target distribution.

No private engine, codec library, shared-engine C header or CLI executable belongs in this package. NativeAOT removes the .NET runtime dependency, but the selected GTK toolkit must still be installed on Linux. Windows uses self-contained WinForms/MWin without GTK. The original project code is GPL-3.0-only. Dependency scanning and a clean-machine installation check remain required before a production package. This directory supplies resources and ownership guidance, not a validated RPM release.
